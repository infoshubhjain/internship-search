# Summer 2027 SWE Internship Tracker

Quick setup for UIUC F-1 international student internship search.

## Files

- `SWE_Internship_Master_Tracker.csv` - 60+ target companies with direct links
- `Search_Queries.csv` - Daily/weekly search URLs for job boards
- `Weekly_Plan.csv` - Daily tasks and reminders
- `ai_automation_prompt.txt` - Copy this to ChatGPT/Claude for automated searching
- `Summer2027_SWE_Tracker_Template.csv` - Empty template for new job discoveries

## Quick Start

1. **Create Google Sheet** named `Summer2027_SWE_Tracker`
2. **Import CSVs** as separate sheets (File > Import > Upload)
3. **Run automation** - Copy `ai_automation_prompt.txt` to an AI agent with browser access
4. **Apply daily** - Focus on Priority 1 (underclassman programs) and Priority 2 (banks)

## Priority System

1. **Underclassman programs** - Google STEP, Microsoft Explore, Meta University, Amazon SDE, Capital One, Uber, Pinterest, Lyft
2. **Banks/fintech** - JPMorgan, Goldman Sachs, Morgan Stanley, Bank of America, Citi, Visa, Mastercard, etc.
3. **F500 non-tech** - Walmart, Target, GM, Ford, John Deere, etc.
4. **Big Tech/unicorns** - Apple, Netflix, Airbnb, Stripe, etc.
5. **Startups/other**

## Key Reminders

- Apply to 5-10 internships daily (don't skip weekends)
- CPT eligibility is critical - check work authorization notes
- Banks typically sponsor CPT
- Keep tracker updated with status (Applied, Interview, Offer, Rejected)
